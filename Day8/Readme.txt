# Day 8 - Employee Salary Prediction

This project demonstrates a complete machine learning data preprocessing workflow using an Employee Salary dataset.

## Workflow

1. Load Dataset
2. Explore Dataset
3. Handle Missing Values
4. Remove Duplicate Records
5. Identify Data Types
6. Encode Categorical Features
7. Scale Numerical Features
8. Split Dataset into Training and Testing Data
9. Train Linear Regression Model
10. Evaluate Model

## Technologies

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Model

Linear Regression

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
